 🏧 ATM Machine Simulation Project
 📌 Project Title

ATM Machine Simulation using HTML, CSS & JavaScript


📖 Project Description

This project is a simple **ATM Machine Simulation Website** created to demonstrate how an ATM works in real life. It allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and exiting the system.

This project is mainly useful for:

* Beginners in web development
* Mini project / college assignment
* Understanding JavaScript logic


🎯 Features

* Secure PIN login system
* Check account balance
* Deposit money
* Withdraw money
* Error handling for insufficient balance
* User-friendly interface
* Real-time balance update

---
🛠️ Technologies Used

* **HTML** – Structure of the ATM interface
* **CSS** – Styling and layout
* **JavaScript** – ATM logic and functionality


 📂 Project Folder Structure


ATM-Machine
 ┣ 📄 index.html
 ┣ 📄 style.css
 ┣ 📄 script.js

▶️ How to Run the Project

1. Download or clone the project folder
2. Open the folder in **VS Code**
3. Double click on `index.html`

   

   Right click → *Open with Live Server*
4. The ATM Machine website will open in your browser


🔑 Default Login Details

* **PIN:** `1234`
* **Initial Balance:** ₹10,000

*(You can change these values in `script.js`)*
